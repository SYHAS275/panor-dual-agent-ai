----------------

tailwind.config.ts      - Tailwind configuration with dark mode and custom theme
tsconfig.json           - TypeScript compiler options and paths


APP DIRECTORY (Next.js 14 App Router)
--------------------------------------
app/page.tsx            - Main page component with state management for upload/analysis flow
app/layout.tsx          - Root layout with metadata, ThemeProvider, global styles
app/globals.css         - Tailwind directives, custom scrollbar, animations, dark mode styles

API ROUTES
----------
app/api/analyze/route.ts  - Handles file upload, text extraction, AI analysis, summarization
app/api/health/route.ts   - Returns health status and configuration info


COMPONENTS (Reusable React Components)
---------------------------------------

AI SERVICES LAYER
-----------------
lib/ai/geminiService.ts    - Google Gemini API integration with prompt formatting
lib/ai/openaiService.ts    - OpenAI ChatGPT API integration and summarization logic
lib/ai/index.ts            - Orchestrates both AI services in parallel, generates summary


FILE PARSERS LAYER
------------------
lib/parsers/pdfParser.ts    - Extracts text from PDF files using pdf-parse library
lib/parsers/imageParser.ts  - OCR for images (PNG, JPG) using Tesseract.js
lib/parsers/docxParser.ts   - Extracts text from Word documents using mammoth
lib/parsers/textParser.ts   - Reads plain text files with UTF-8 encoding
lib/parsers/index.ts        - Routes to appropriate parser based on file extension

ENVIRONMENT VARIABLES
=====================

Required:
- OPENAI_API_KEY                  - OpenAI API key (starts with sk-)
- GEMINI_API_KEY                  - Google Gemini API key

Optional:
- NODE_ENV                        - Environment (development/production)
- MAX_FILE_SIZE                   - Maximum file size in bytes (default: 10485760)
- ALLOWED_FILE_TYPES              - Comma-separated list of allowed extensions
- API_TIMEOUT                     - API request timeout in milliseconds (default: 60000)
- RATE_LIMIT                      - Requests per minute (default: 10)


DATA FLOW SUMMARY
=================

1. User uploads file via FileUpload component (app/page.tsx)
2. FormData sent to POST /api/analyze (app/api/analyze/route.ts)
3. File parsed by appropriate parser (lib/parsers/*.ts)
4. Text extracted and sent to both AI services in parallel (lib/ai/index.ts)
   - Gemini API (lib/ai/geminiService.ts)
   - OpenAI API (lib/ai/openaiService.ts)
5. Both responses sent to OpenAI for summarization
6. All three responses returned to frontend
7. ResponseDisplay shows results in 3-column layout
8. Temporary file deleted from uploads/ directory


SECURITY FEATURES
=================

✓ API keys stored in environment variables, never exposed to client
✓ File type validation (whitelist: .pdf, .png, .jpg, .jpeg, .docx, .txt)
✓ File size limits (default: 10MB)
✓ Automatic file cleanup after processing
✓ Input sanitization for questions
✓ Error messages don't leak sensitive information
✓ Structured logging with Winston (no sensitive data logged)
✓ HTTPS recommended for production
✓ Security headers configurable in next.config.js
